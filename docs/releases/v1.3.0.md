# AI Engineering Companion v1.3.0

**Release date:** 2026-11-02<br>
**Platform:** Windows 10/11 x64 desktop; browser and installable PWA from source or self-hosted deployment

This is the v1.3.0 feature and verification release of AI Engineering Companion. It adds the Syllabus Library, structured syllabus parsing, account isolation hardening, expanded source-grounded tutoring, and a rebuilt Windows package.

See [CHANGELOG.md](https://github.com/jibinpj-3665/ai-engineering-companion/blob/main/CHANGELOG.md) for the full feature list.

## Release caveats

Read these before installing or publishing this release.

- **The Windows installer is unsigned.** Windows SmartScreen may warn that the publisher is unknown. No code-signing certificate is configured. The installer has not been installed or uninstalled on a clean Windows machine; the unpacked desktop app and packaged backend were smoke-tested.
- **The final live Gemini verification is quota-blocked.** Connection and separate cited engineering, numerical, and streaming calls succeeded earlier, but the free-tier limit of 20 requests per day was exhausted before one all-green end-to-end live run could complete. The app falls back to clearly labelled offline retrieval when a provider fails.
- **Docker, PostgreSQL, and cloud deployment are not yet runtime-verified.** The Dockerfile and Compose stack are included, but no Docker image build, PostgreSQL deployment, reverse-proxy deployment, or hosted smoke test was completed for this release. Do not describe the web path as production-verified until those checks pass.
- **OCR and SMTP are not verified.** The Dockerfile installs Tesseract and the backend includes SMTP support, but neither OCR nor password-reset email delivery was exercised in the release environment.

## Installation

### Windows desktop

1. Download `AI-Engineering-Companion-Setup.exe`.
2. Verify its SHA-256 checksum against the value below.
3. Run the installer. Confirm the SmartScreen prompt only if you trust this build.
4. Desktop data is stored in `%LOCALAPPDATA%\AIEngineeringCompanion`. Uninstalling does not delete this folder.

No API key is bundled. Offline retrieval works immediately; configure an AI provider in **Settings → AI provider** when online model access is wanted.

### Web deployment

The Docker/Compose path is a preview for v1.3.0 and has not been runtime-verified. Read [docs/WEB_DEPLOYMENT.md](https://github.com/jibinpj-3665/ai-engineering-companion/blob/main/docs/WEB_DEPLOYMENT.md) and run the container, PostgreSQL, and hosted smoke checks before exposing it to users.

## Upgrade notes

- Back up `%LOCALAPPDATA%\AIEngineeringCompanion` before upgrading.
- Startup schema migration is automatic and backfills chunk ownership from the owning document.
- Superseded or unindexed documents are excluded from search, retrieval, and AI status counts.
- Per-account backups exclude credentials, sessions, and other accounts.
- If exposing the web app, require accounts with `AEC_REQUIRE_AUTH=1` and read the security guidance in [SECURITY.md](https://github.com/jibinpj-3665/ai-engineering-companion/blob/main/SECURITY.md).

## Known limitations

- This is a study aid, not a replacement for lectures, textbooks, laboratories, or university academic-integrity rules.
- AI-generated material can be wrong; verify derivations, numerical results, and citations against the original pages.
- Remote AI, SMTP, and cloud behavior depends on credentials and services that are not bundled.
- The web deployment is single-replica and uses a local upload volume; horizontal scaling and S3-compatible object storage are not implemented.
- OCR requires Tesseract on desktop.
- There is no admin role, email verification, SSO, or audit console.
- Retrieval uses relational `DocumentChunk` records. No ChromaDB index is included.
